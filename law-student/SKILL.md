# 法律学习技能

## 核心能力

法考备考辅助、法律研习工具、案例分析训练。

## 学习模式

### 记忆卡片（flashcards）

**莱特纳记忆桶系统** — 按科目Markdown存储：

- `--generate [科目]` — 从大纲/笔记生成卡片
- `--drill [科目]` — 训练模式，自我评估
- `--review` — 复习过期卡片
- `--stats` — 查看学习进度

### IRAC法律分析训练

**IRAC方法：** Issue → Rule → Application → Conclusion

- 给出案例材料 → 识别法律问题 → 检索规则 → 适用分析 → 得出结论

### 案例摘要训练

**case brief结构：**
- 基本事实（Facts）
- 争议焦点（Issue）
- 法院裁判（Holding）
- 裁判理由（Reasoning）

### 法律写作练习

- 法律备忘录（Legal Memo）
- 案例分析（Case Analysis）
- 论证推理（Legal Reasoning）

## 中国法考体系

### 考试结构

| 阶段 | 科目 |
|---|---|
| 客观题 | 民法、刑法、行政法、民诉、刑诉、商法、法理、宪法、中国法律史、国际法等 |
| 主观题 | 法治思想、法理学、民法、刑法、行政法、民诉 |

### 核心科目要点

**民法：** 物权、合同、人格权、婚姻家庭、继承、侵权
**刑法：** 犯罪论、刑罚论、各罪构成要件
**行政法：** 行政主体、行政行为、行政复议、行政诉讼
**民诉：** 主管、管辖、当事人、证据、程序

## 学习方法

1. **建立知识框架** — 先构建学科体系，再填充细节
2. **法条记忆** — 重点法条须背诵，理解适用场景
3. **案例分析** — 多做真题，培养法律思维
4. **请求权检索** — 民法案例的核心方法
5. **模拟考试** — 限时练习，提高应试能力

## 注意事项

- 法考客观题：每科150题，3小时
- 法考主观题：4小时，案例分析为主
- 答题注意时间管理，不要在某题上过度纠缠
- 主观题：法治思想论述+民法+刑法+民诉/行政法（选做）
