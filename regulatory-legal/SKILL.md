# 监管合规法律技能

## 核心能力

行政处罚应对、行政复议、行业监管合规全流程服务。

## 工作流程

### 行政处罚应对（主入口）

1. **程序阶段识别** — 立案/调查/告知/听证/决定
2. **违法事实认定审查** — 证据是否充分、事实是否清楚
3. **法律依据适用分析** — 定性是否准确、条款引用是否正确
4. **处罚幅度评估** — 罚款金额/没收/停产停业是否合理
5. **陈述申辩** — 起草陈述申辩意见
6. **听证程序参加** — 听证申请、陈述申辩

### 行政复议流程

1. **确认复议时效** — **60日**（自知道具体行政行为之日起）
2. **选择复议机关** — 同级政府或上级主管部门
3. **起草复议申请书** — 复议请求、事实与理由、法律依据
4. **准备证据材料** — 原具体行政行为的依据
5. **等待复议决定** — 可能：维持/撤销/变更/责令履行

## 行政处罚程序阶段

```
立案 → 调查 → 事先告知（告知陈述申辩权）→ 听证（当事人申请）→ 决定 → 送达执行
```

## 常见处罚类型

| 类型 | 说明 |
|---|---|
| 警告 | 精神罚 |
| 罚款 | 并处罚款/单处罚款 |
| 没收违法所得 | 没收非法收益 |
| 责令停产停业 | 资格罚 |
| 吊销许可证 | 资格罚（最重） |
| 通报批评 | 声誉罚 |

## 行业监管框架

| 行业 | 监管主体 | 核心法规 |
|---|---|---|
| 金融 | 一行两会 | 银行法/证券法/保险法 |
| 医疗 | 卫健委/药监局 | 医疗机构管理条例/药品管理法 |
| 教育 | 教育部/市场监管 | 教育促进法/民办教育促进法 |
| 互联网 | 网信办/工信部 | 网络安全法/电子商务法 |
| 食品 | 市场监管总局 | 食品安全法 |
| 产品 | 市场监管总局 | 产品质量法/消费品召回管理办法 |

## 注意事项

- 行政处罚时效一般为**2年**，特殊情形可延长至**5年**
- 当事人有陈述申辩权和听证申请权——务必积极行使
- 复议期间具体行政行为**不停止执行**，除非复议机关决定停止
- 监管处罚的裁量基准需关注当地司法解释和指导案例
- 合规整改不仅针对本次违规，更需建立**长效机制**
