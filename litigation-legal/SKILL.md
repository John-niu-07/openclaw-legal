# 诉讼法律技能

## 核心能力

民事诉讼、仲裁、强制执行全流程支持——文书撰写、证据策略、程序管理、判例研究。

## 工作流程

### 诉讼需求分析

1. **明确纠纷性质** — 合同纠纷/侵权纠纷/不当得利/物权纠纷
2. **评估诉讼时效** — 计算时效是否届满、是否存在中断中止
3. **确认当事人** — 原告/被告/第三人，主体资格
4. **分析管辖连接点** — 被告住所地/合同履行地/侵权行为地/协议管辖

### 诉讼文书撰写

| 文书 | 核心要素 |
|---|---|
| 起诉状 | 诉讼请求、事实与理由、法律依据 |
| 答辩状 | 反驳要点、抗辩事由（实体抗辩+程序抗辩） |
| 证据目录 | 证据名称、证明内容、证据来源、页码 |
| 代理词 | 争议焦点、法律适用、事实认定意见 |

### 要件分析表构建

**claim-chart 技能** — 构建或审查要件分析表：
- 专利权利要求对照表（侵权/无效）
- 民事构成要件分析表（任何诉讼请求/抗辩）
- 每个单元格附精确引用，缺口检测为优先输出

### 证据策略

1. **确定证明对象** — 原告：请求权基础事实 / 被告：抗辩事实
2. **分配举证责任** — 谁主张谁举证原则
3. **梳理现有证据** — 真实性、合法性、关联性三性审查
4. **识别证据缺口** — 补强方案（证人申请/鉴定申请）
5. **准备质证意见** — 针对对方证据的反驳点

## 关键时效

| 类型 | 时效/期间 |
|---|---|
| 普通民事纠纷诉讼时效 | **3年** |
| 人身伤害赔偿 | **1年** |
| 建筑工程款 | **18年** |
| 行政诉讼 | **6个月** |
| 仲裁时效 | **3年**（涉外的2年） |
| 申请执行时效 | **2年** |
| 财产保全 | 诉前30日/诉中 |

## 注意事项

- 口头协议同样具有法律效力，但举证困难
- 诉讼时效因起诉/仲裁/主张权利而中断，从中断之日起重新计算
- 管辖约定优先，但专属管辖和级别管辖除外
- 证据应在举证期限内提交，逾期可能导致失权
- 诉前财产保全可有效防止对方转移财产
- 执行难问题：提供明确财产线索是关键
