# 个人信息与数据法律技能

## 核心能力

个人信息保护、数据安全、网络安全合规全流程服务——隐私政策、DSAR响应、数据出境、监管应对。

## 工作流程

### DSAR处理流程（数据主体权利请求）

1. **接收并分类请求** — 查阅/复制/更正/补充/删除/可携带
2. **身份验证** — 按系统逐一定位数据
3. **评估豁免** — 是否存在法定豁免情形
4. **起草回复** — 确认函 + 实质回复函
5. **响应时限** — **15个工作日**

### PIA生成流程（隐私影响评估）

1. **检查触发条件** — 是否确实需要PIA
2. **录入产品团队** — 收集功能描述、数据类型、处理目的
3. **构建评估框架** — 处理合法性基础、数据最小化、风险评估
4. **输出评估报告** — 内部格式 + 审批流程

### 主要子技能

| 子技能 | 触发场景 |
|---|---|
| `dsar-response` | 数据主体权利请求处理 |
| `pia-generation` | 个人信息保护影响评估 |
| `dpa-review` | 数据处理协议审查 |
| `reg-gap-analysis` | 合规差距分析 |
| `policy-monitor` | 监管动态跟踪 |

## 数据主体权利清单

| 权利 | 说明 | 响应时限 |
|---|---|---|
| 查阅/复制 | 获取个人信息副本 | 15工作日 |
| 更正/补充 | 纠正不准确信息 | 15工作日 |
| 删除 | 撤回同意/目的实现/违法处理 | 15工作日 |
| 可携带 | 获取结构化机器可读格式 | 15工作日 |
| 撤回同意 | 撤回先前给予的同意 | 即时生效 |
| 拒绝自动化决策 | 拒绝仅通过自动化决策作出的决定 | 15工作日 |

## 数据分类分级

| 类别 | 示例 | 保护要求 |
|---|---|---|
| 一般个人信息 | 姓名、邮箱、电话 | 基本保护 |
| 敏感个人信息 | 生物识别、位置、医疗、金融账户 | 单独同意 + 强化保护 |
| 重要数据 | 关键基础设施数据、出口管制数据 | 安全评估 + 审批 |

## 注意事项

- 处理敏感个人信息需取得**单独同意**
- 个人信息委托处理需签订书面合同并监督
- 数据留存期限不超过实现处理目的所必需的**最短时间**
- 自动化决策需提供**不针对个人特征**的选项
- 向境外提供个人信息需通过**国家网信部门安全评估**
- 违规最高罚款可达上一年度营业额的**5%**
