# 法律诊所技能

## 核心能力

简单法律问题解答、常见法律文书起草、公益法律咨询支持。

## 工作流程

### 法律问题初步评估

1. **问题分类** — 劳动/合同/侵权/婚姻家庭/消费/其他
2. **复杂度判断** — 简单问题直接回答/复杂问题建议律师介入
3. **管辖判断** — 确认管辖部门和程序
4. **风险提示** — 告知用户注意保留证据

### 文件起草（主功能）

**支持的文件类型：**
- 劳动争议仲裁申请书
- 离婚起诉状
- 人身损害赔偿起诉状
- 律师函/催告函
- 合同（简版）
- 答辩状（简版）

**起草流程：**
1. 收集事实（缺失则标注，绝不猜测）
2. 选择模板
3. 填充内容
4. 标注"须律师审查"

### 简单法律问题参考

| 类型 | 常见问题 |
|---|---|
| 劳动 | 试用期、解雇赔偿、工伤认定、劳动仲裁 |
| 合同 | 合同效力、违约责任、解除条件 |
| 侵权 | 交通事故赔偿、医疗纠纷、人身损害 |
| 婚姻 | 离婚程序、财产分割、抚养权 |
| 消费 | 退货退款、欺诈赔偿、产品责任 |
| 借贷 | 借条效力、还款义务、诉讼时效 |

## 重要提示

⚠️ **免责声明**：本技能提供的是法律信息参考和文书初稿，**不是法律意见**，**不能替代律师的专业判断**。

复杂案件、有争议的案件、涉及较大利益的案件，建议：
- 咨询专业律师
- 申请法律援助
- 寻求法律帮助

## 服务边界

**可以做的：**
- 简单法律问题解答
- 常见文书模板起草
- 法律程序指引
- 权利义务说明

**不能做的：**
- 代理诉讼
- 提供正式法律意见
- 处理复杂法律关系
- 代替律师出庭

## 注意事项

- 诉讼时效：普通民事纠纷**3年**，劳动争议**1年**
- 劳动仲裁前置：劳动争议须先仲裁再诉讼
- 保留证据：聊天记录、合同、发票、照片等
- 管辖选择：被告住所地或合同履行地法院
