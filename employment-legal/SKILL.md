# 劳动法律技能

## 核心能力

劳动关系全流程法律服务——招聘入职、合同管理、薪酬福利、工伤认定、竞业限制、劳动争议。

## 工作流程

### 解除审查（主流程）

1. **加载实践画像** — 管辖范围、高风险标记、经济补偿惯例
2. **逐项检查清单** — 解除条件、通知义务、程序合规
3. **高风险标记检测** — 三期员工、医疗期、工伤、职业病、老员工
4. **管辖地规则提取** — 按省/直辖市确定补偿标准、通知期、社保转移
5. **经济补偿/赔偿金计算** — N+1/2N/其他补偿项目
6. **最终工资支付时点** — 按管辖地逐项确认
7. **如触发高风险标记** — 按上报表升级，未经签批不得继续

### 主要子技能

| 子技能 | 触发场景 |
|---|---|
| `termination-review` | 劳动合同解除审查 |

### 补偿计算基准

| 解除类型 | 补偿规则 |
|---|---|
| 协商解除（单位提出） | N个月工资 |
| 员工过失解除 | 无补偿 |
| 员工非过失解除 | N+1（或提前30日通知） |
| 经济性裁员 | N+1 |
| 合同到期不续（单位不续） | N个月工资 |
| 违法解除 | 2N |
| 备注 | 月工资=解除前12个月平均工资 |

### 关键时效

- 劳动仲裁时效：**1年**（知道或应当知道权利被侵害之日起）
- 工伤认定：**30日内**（单位）/ **1年内**（个人）
- 加班费争议：**2年**（拖欠工资适用）

## 注意事项

- 用人单位不得收取押金、扣押证件
- 试用期也需缴纳社保，试用期不得单独约定
- 经济补偿按工作年限计算，每满1年支付1个月工资
- 违法解除劳动合同的赔偿金为经济补偿的2倍
- 劳务派遣只能在临时性、辅助性、替代性岗位上使用
- 工伤认定时效为事故伤害发生后30日内（特殊可延长）
