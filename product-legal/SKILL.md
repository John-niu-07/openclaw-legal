# 互联网产品法律技能

## 核心能力

互联网产品全生命周期法律合规——用户协议、隐私政策、商业模式合规、平台责任、消费者权益。

## 工作流程

### 产品法律风险评估（主入口）

1. **梳理产品功能和商业模式** — 核心功能、收费模式、用户类型
2. **识别涉及的法律法规** — 电商法/消保法/广知法/个保法/ICP许可
3. **评估各环节法律风险点** — 准入、内容、收费、消费者保护
4. **确定需要的前置审批或备案** — ICP、游戏版号、特殊行业资质

### Launch Review（新品上线审查）

1. **按七类框架审查** — 商业模式、收费、用户协议、隐私、内容、安全、合规
2. **识别风险项** — 标注🔴🟠🟡🟢
3. **给出合规建议** — 需要修改的具体条款和替代方案

### 主要子技能

| 子技能 | 触发场景 |
|---|---|
| `launch-review` | 新功能/产品上线合规审查 |
| `feature-risk-assessment` | 功能法律风险评估 |
| `marketing-claims-review` | 营销宣传合规审查 |
| `is-this-a-problem` | 问题定性判断 |

## 七类合规框架

| 类别 | 审查要点 |
|---|---|
| 商业模式合规 | 许可证/备案要求、禁止性行为 |
| 收费合规 | 明码标价禁止价格欺诈、退款政策 |
| 用户协议 | 格式条款合规性、管辖约定 |
| 隐私政策 | 收集目的最小化、用户权利响应 |
| 内容管理 | UGC审核机制、知产侵权处理 |
| 安全合规 | 数据安全、未成年人保护 |
| 行业特定 | 药品/食品/金融等特殊行业资质 |

## ICP管理体系

| 类型 | 适用范围 |
|---|---|
| ICP备案 | 非经营性互联网信息服务 |
| ICP许可证 | 经营性互联网信息服务（电商平台、付费内容等） |
| 网络出版服务许可证 | 在线出版、数字内容发布 |
| 新闻信息服务许可证 | 时政类新闻发布 |

## 注意事项

- 平台对用户行为承担连带责任，而非完全免责
- 格式条款若加重对方责任、排除对方权利，可能被认定无效
- 涉及资金归集需确保有支付牌照或银行合作
- 广告法对极限用语和虚假宣传有严格禁止
- 个人信息处理须遵循**最小必要原则**
