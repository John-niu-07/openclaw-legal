# AI治理法律技能

## 核心能力

AI产品和算法合规全流程服务——备案、评估、政策制定、合规审查。

## 工作流程

### AI使用政策起草（主入口）

1. **读取监管注册表** — 适用法规清单
2. **确认AI系统清单** — 已在使用的AI工具
3. **评估公司实践位置** — 风险偏好、透明度承诺
4. **确定受众** — 内部员工/外部客户/两者
5. **选择模板并填充** — 输出政策初稿
6. **附"仍需决定"清单** — 政策解决不了的问题需人拍板

### 算法备案流程

1. **识别备案类型** — 算法推荐/深度合成/自动驾驶/其他
2. **准备备案材料** — 算法说明书、安全评估报告等
3. **提交网信部门** — 通过互联网信息服务算法备案系统
4. **跟踪备案状态** — 获取备案号

## 中国AI监管体系

| 法规 | 主管机关 | 核心要求 |
|---|---|---|
| 生成式人工智能服务管理暂行办法 | 网信办 | 服务提供者须安全评估、算法备案 |
| 互联网信息服务算法推荐管理规定 | 网信办 | 算法推荐须备案、透明度、不得歧视 |
| 互联网信息服务深度合成管理规定 | 网信办 | 深度合成须显著标注、溯源 |
| 汽车数据安全管理若干规定 | 工信部 | 车载数据分类、境内存储、出境评估 |
| 数据安全法 | 网信办 | 数据分类分级、重要数据保护 |
| 个人信息保护法 | 网信办 | 自动化决策须告知、不得歧视 |

## 核心合规要求

1. **算法备案** — 算法推荐服务须向网信部门备案
2. **安全评估** — 达到一定规模须申报安全评估
3. **数据境内存储** — 重要数据须境内存储
4. **标注义务** — AI生成内容须显著标注
5. **透明度要求** — 须告知用户自动化决策逻辑

## 注意事项

- 生成式AI服务提供者须对数据进行标注
- 不得根据用户偏好实施歧视性定价
- AI生成内容须有明显标识防止混淆
- 涉及人身安全的AI系统须取得相关资质
- AI服务协议需明确责任划分和免责条款
