# 知识产权法律技能

## 核心能力

商标、专利、著作权、商业秘密的取得、保护、许可、转让及侵权处理全流程服务。

## 工作流程

### 知识产权侵权筛查（主入口）

**这是初步筛查，而非侵权认定。** 侵权分析依赖大量事实且法律上非常复杂。

1. **识别权利类型** — 商标/著作权/专利/商业秘密
2. **构建要件分析表** — 每种权利类型的侵权构成要件
3. **逐要件核查** — 各方有利/不利因素标注
4. **产出标注清单** — 标注各方有利/不利因素，不作侵权结论
5. **给出追诉建议** — 是否值得追诉、如何追诉、律师审查必要

### 商标侵权判断要素

1. **混淆可能性** — 商标近似 + 商品/服务类似
2. **主观恶意** — 明知而模仿
3. **在先权利冲突** — 商号权、著作权、外观设计
4. **驰著名商标保护** — 跨类保护、恶意注册

### 专利侵权判断

1. **技术特征比对** — 权利要求全部技术特征
2. **等同侵权** — 手段、功能、效果基本相同
3. **先用权抗辩** — 原有范围内制造使用
4. **无效抗辩** — 专利不符合新颖性/创造性

### 著作权侵权类型

- 未经许可复制、发行、表演、放映、广播、信息网络传播
- 剽窃他人作品
- 未经许可改编、翻译、注释、整理

## 注意事项

- 商标侵权诉讼时效：**3年**（知道或应当知道侵权之日起）
- 专利侵权诉讼时效：**3年**
- 著作权侵权诉讼时效：**3年**
- 商业秘密侵权：不要求时效限制，但持续侵权从结束起算
- 知识产权海关保护需在海关总署备案
- 软件开源合规需注意GPL传染性等问题
