# 公司法律技能

## 核心能力

公司设立、治理结构、股权融资、并购重组全流程法律支持。

## 工作流程

### 董事会/股东大会纪要起草

1. **读取公司治理结构** — 章程规定、议事规则
2. **确认会议类型** — 股东会/董事会/专门委员会
3. **收集会议信息** — 议程、演示文稿、预读材料
4. **起草符合格式的会议纪要** — 从种子文件学习格式
5. **处理书面决议** — 替代会议的书面决定

### 尽职调查（并购场景）

1. **加载尽调结构** — 重要性阈值、内部格式偏好
2. **确认文件范围和列** — 模式构建
3. **样本运行** — 3-5份文件测试模式
4. **展开** — 每份文件并行处理，逐格返回：值+状态+引文+位置
5. **归一化** — 异常和不一致检测
6. **输出** — Excel/CSV/markdown + 摘要

## 表格审查系统（核心功能）

**tabular-review 技能** — 一行一文件、一列一数据点：

| 类型 | 返回内容 |
|---|---|
| `verbatim` | 文件中的确切引文 |
| `classify` | 固定选项之一（存在/不存在/须经同意等） |
| `date` | ISO格式日期 |
| `currency` | 数字+货币代码 |

**未找到的三种状态：**
- `not_present` — 已读文件，该条款不存在
- `unclear` — 有内容但无法自信分类
- `needs_review` — 找到了但需人工判断

## 关键修订要点（公司法2024）

- **限期认缴制** — 5年内缴足（除特定行业）
- **出资加速到期** — 穷尽执行仍不能清偿时加速
- **股东失权** — 未缴纳出资经催缴后失权
- **审计委员会** — 股份有限公司可设
- **董监高义务** — 勤勉义务+忠实义务明确化
- **公司担保** — 对股东/实控人担保须股东会决议
- **股权转让** — 有限公司股权转让新规则
- **人格否认** — 横向否认明确

## 注意事项

- 股东会/董事会决议效力：有效/可撤销/无效
- 关联担保必须经股东会表决（非关联股东过半数）
- 股权转让优先购买权：30日行权期限
- 一致行动人需合并计算表决权
